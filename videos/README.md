# 📹 Videos para Demostraciones

Esta carpeta contiene los videos locales que se reproducen en los modales del slide 3.

## 🎬 Archivos de Video Requeridos

### Para el panel "IA desde Navegador Web":
- `web-ia-demo.mp4` - Video principal (formato recomendado)
- `web-ia-demo.webm` - Video alternativo para mejor compatibilidad web
- `web-ia-poster.jpg` - Imagen de poster (opcional, se muestra antes de reproducir)

### Para el panel "GitHub Copilot Integrado":
- `copilot-demo.mp4` - Video principal (formato recomendado) 
- `copilot-demo.webm` - Video alternativo para mejor compatibilidad web
- `copilot-demo-poster.jpg` - Imagen de poster (opcional, se muestra antes de reproducir)

## 📐 Especificaciones Recomendadas

### Videos (.mp4 / .webm):
- **Resolución**: 1280x720 (HD) o 1920x1080 (Full HD)
- **Duración**: 
  - IA Web: 30-120 segundos (demostrar proceso completo)
  - Copilot: 15-60 segundos (demostrar velocidad)
- **Formato**: MP4 (H.264) para mejor compatibilidad
- **Tamaño**: Máximo 50MB por video para carga rápida

### Imágenes Poster (.jpg):
- **Resolución**: 1280x720 (misma proporción que el video)
- **Formato**: JPG optimizado
- **Tamaño**: Máximo 500KB

## 🎯 Contenido Sugerido

### Video "IA desde Navegador Web":
- Abrir navegador web
- Ir a ChatGPT/Claude
- Escribir prompt para generar código
- Esperar respuesta
- Copiar código manualmente
- Cambiar a VS Code/IDE
- Pegar y ajustar código
- Mostrar tiempo total: 3-5 minutos

### Video "GitHub Copilot Integrado":
- Abrir VS Code con Copilot
- Escribir comentario o función
- Mostrar sugerencia automática de Copilot
- Aceptar con Tab
- Continuar codificando fluidamente
- Mostrar tiempo total: 5-10 segundos

## 🔧 Herramientas de Grabación Recomendadas

- **OBS Studio** (gratuito) - Para screen recording
- **Camtasia** - Para edición profesional
- **QuickTime Player** (Mac) - Para grabaciones simples
- **Windows Game Bar** (Windows) - Grabación integrada

## 📱 Compatibilidad

El sistema soporta:
- ✅ MP4 (H.264) - Mejor compatibilidad
- ✅ WebM - Menor tamaño de archivo
- ✅ Fallback automático si video no existe
- ✅ Poster images para mejor UX
- ✅ Controles nativos del navegador
